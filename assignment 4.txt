Phase 12: Deploy Cloud Run Validator

Linux/Bash
gcloud run deploy $VALIDATOR_SERVICE \
  --source ./cloud_run_validator \
  --region $REGION \
  --service-account $VALIDATOR_SA@$PROJECT_ID.iam.gserviceaccount.com \
  --no-allow-unauthenticated

Powershell
gcloud run deploy transaction-validator `
  --source ./cloud_run_validator `
  --region asia-southeast1 `
  --service-account validator-sa@transactional-496815.iam.gserviceaccount.com `
  --no-allow-unauthenticated

deploy đang lỗi do thiếu quyền đọc object trong Cloud Storage. Khi deploy Cloud Run bằng --source, 
source code sẽ được upload lên một bucket tạm của Google Cloud, rồi service account build cần đọc source đó để build container. Nó đang không đọc được.

gcloud projects add-iam-policy-binding transactional-496815 \
  --member="serviceAccount:340954912438-compute@developer.gserviceaccount.com" \
  --role="roles/storage.objectViewer"
